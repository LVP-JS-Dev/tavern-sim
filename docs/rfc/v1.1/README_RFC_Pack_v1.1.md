# Internal RFC Pack — Tavern Tycoon — v1.1 (Spec-First)

## Purpose
This pack defines production-stable specifications for the simulation-heavy version:
- deterministic simulation core
- state/save/load with versioning + integrity rules
- reproducible RNG & replay
- world placement constraints
- director-driven event model
- heroes + personality traits + corruption
- adventure + loot
- event log & notifications
- performance constraints
- asset pipeline constraints
- architecture integration (Phaser/React/domain boundaries)
