# External Discussions --- Process Diagram

``` mermaid
flowchart TD

    IDEAS[Concept / Discussion]
    REFS[Reference Games Analysis]
    PRD[PRD Expansion]
    ART[Art Prompt Tables]
    IMPL[Implementation Pack Spec]
    OUTPUT[Structured Deliverables]

    IDEAS --> REFS
    REFS --> PRD
    PRD --> ART
    ART --> IMPL
    IMPL --> OUTPUT
```

## Flow Explanation

1.  Ideas emerge from discussion.
2.  Reference games analyzed for style and mechanics.
3.  PRD updated with visual and gameplay standards.
4.  Asset tables prepared for generation.
5.  Implementation pack structured.
6.  Output delivered as formal documentation.
