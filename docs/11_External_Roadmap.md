# External Dialogues --- Process Roadmap

## Phase 1 --- Concept Clarification

-   Identify core gameplay idea
-   Define MVP constraints
-   Select visual references

## Phase 2 --- Documentation Structuring

-   Expand PRD
-   Define visual standards
-   Formalize implementation expectations

## Phase 3 --- Asset Preparation

-   Create art prompt tables
-   Define sprite formats
-   Specify dimensions

## Phase 4 --- Implementation Packaging

-   Produce full implementation pack
-   Mark assumptions clearly
-   Provide deterministic architecture

## Phase 5 --- Delivery

-   Structured markdown artifacts
-   Downloadable documentation
-   Clear separation of project vs external scope
