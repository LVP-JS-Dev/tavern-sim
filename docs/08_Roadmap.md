# Tavern Tycoon --- Development Roadmap

-   Project scaffolding (Vite / Next / custom build)
-   TypeScript strict mode
-   Folder structure: game/, ui/, domain/, shared/
-   Telegram Mini App integration
-   Basic state serialization

-   Phaser scene setup
-   Static tavern background

-   Idle income tick system
-   Floating gold numbers
-   LocalStorage persistence

## Phase 2 --- Hero System

-   Hero data model
-   Upgrade logic
-   Hero list screen (React)
-   Hero detail screen
-   Rarity tiers

## Phase 3 --- UI Systems

-   Upgrade screen
-   Daily rewards screen
-   Invite system screen
-   Offline progress popup

## Phase 4 --- Visual Polish

-   Idle animations
-   Candle light flicker
-   Particle effects
-   UI micro-animations
-   Pixel polish pass

## Phase 5 --- Optimization

-   Bundle size reduction
-   Sprite optimization
-   Performance testing on mobile WebView
-   Deterministic offline validation

## MVP Release Criteria

-   Stable idle loop
-   All core screens functional
-   No critical UI bugs
-   Deterministic offline income
-   Optimized asset loading
